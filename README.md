# 🏢 SQL Data Warehouse Project

👋 **Welcome to my Data Engineering project!**

This repository contains the full workflow and SQL scripts for building a modern Data Warehouse. The project demonstrates the transition from raw data extraction to a business-ready dimensional model.

## 📂 Project Structure

- `datasets/` : Contains the raw CSV data files used for this project.
- `documents/` : Project documentation, architecture diagrams, and notes.
- `scripts/` : All SQL scripts (DDL, DML, Stored Procedures).
- `tests/` : Data quality and validation tests.

## ⚙️ Requirements
- SQL Server (or any standard RDBMS)
- SQL Server Management Studio (SSMS) or Azure Data Studio
- Basic understanding of ETL processes and Star Schema
